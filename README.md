# PDF-чек-мейкер

## О проекте
Учебный проект на Python для автоматического создания PDF-чеков и счетов из файлов CSV и JSON с использованием HTML-шаблонов.

## Структура проекта
- `generate_invoice.py` — основной Python-скрипт.
- `data/` — тестовые данные CSV и JSON.
- `templates/` — HTML-шаблоны документов.
- `output/` — готовые PDF-документы.
- `requirements.txt` — необходимые библиотеки.

## Как запустить
Откройте терминал в папке проекта и выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe generate_invoice.py
```

В меню выберите файл данных, HTML-шаблон и номер документа.

Готовый PDF сохраняется в папке `output` и открывается автоматически.
